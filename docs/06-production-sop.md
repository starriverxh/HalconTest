# PCB 弹性钢针插入视觉项目：完整开发与生产 SOP

## A. 项目立项与需求冻结

### A1. 收集产品数据

必须拿到：

- PCB CAD/Gerber、孔位坐标和公差；
- 针径、孔径、有效间隙、针数、节距和针排跨度；
- 针尖倒角、弹簧行程、允许侧向力和插入力；
- PCB板厚、翘曲范围、绿油/焊盘/孔的表面状态；
- 节拍、换型时间、追溯保存期和环境温度。

### A2. 定义精度口径

书面确认 0.05 mm 是单轴、公差带还是径向最大误差。推荐定义：

~~~text
E_xy = sqrt((X_tip-X_hole)^2 + (Y_tip-Y_hole)^2) <= 0.05 mm
~~~

同时定义 θ、Z、插入力、良率、误检/漏检和 Cpk 门槛。

### A3. 建立误差预算

给视觉定位、标定、机构重复精度、T轴、板高/视差、针变形分别分配预算。参考 `docs/03` 的 RSS 示例。最终目标应留至少 20% 工程余量。

## B. 可行性与光学 DOE

### B1. 样件矩阵

至少准备 3 批 PCB，包括正常良品、最亮/最暗绿油、氧化/污染、最大/最小孔、最大翘曲、正常针、弯针、缺针和换装后的针排。

### B2. 光源实验

每种候选光源固定相机、镜头和距离，记录光源类型/颜色/角度/电流、曝光/增益/光圈、中心四角灰度、对比度、饱和比例、100次定位均值/3σ/范围、最差样件漏检误检。

通孔优先测试准直背光；金属焊盘测试同轴；圆柱边缘测试低角暗场；复杂高反光表面测试穹顶漫射。

### B3. 冻结 FOV 和分辨率

~~~text
物方像素尺寸 = FOV宽度 / 横向像素数
~~~

目标建议不大于 0.015~0.020 mm/px。若一个孔只有几像素，不要用“亚像素”作为选型补救。

## C. 机械和电气设计

### C1. 推荐结构

- 固定下视相机定位 PCB；
- 固定上视相机检查真实针尖；
- 独立 Z 测高；
- XYT微量顺应或导向梳；
- 插入力和位移同步采样。

### C2. 基准与夹具

- PCB三点支撑并可靠压紧，避免压弯；
- 相机、光源、镜头支架有定位销和防松；
- 视觉目标尽量靠近实际插孔；
- T轴转心、相机光轴和Z轴关系必须可标定。

### C3. 触发时序

1. PLC移动到拍照位；
2. 轴到位并等待振动衰减；
3. PLC发硬触发给相机和频闪；
4. HALCON取到带时间戳图像；
5. Socket返回业务结果；
6. PLC检查补偿限值和安全区后运动。

## D. HALCON 离线开发

### D1. 数据管理

原图按产品、批次、时间、曝光、光源和结果分类，禁止用压缩截图代替原始图。

### D2. PCB孔位算法

~~~text
ROI
 -> 图像健康检查
 -> 阈值/边缘
 -> 连通域
 -> 面积、圆度、半径筛选
 -> 亚像素圆/轮廓拟合
 -> 数量、间距、直线度一致性
 -> 像素到机器坐标
~~~

### D3. 针尖算法

~~~text
针排ROI
 -> 背光轮廓/端面边缘
 -> 每根针中心并排序
 -> 节距、直线度、缺针、弯针
 -> 针排中心和θ
 -> 工具TCP
~~~

所有阈值进入配方；过程必须输出具体NG原因。

### D4. 回归测试

每次改算法都对固定数据集运行，记录检出率、假目标率、X/Y/θ偏差、均值、3σ、最大误差、平均和P99运行时间。

## E. 标定 SOP

### E1. 相机内参/畸变

1. 相机、镜头、光圈、焦距锁紧；
2. 使用计量级玻璃标定板；
3. 在中心、四角、不同姿态采集；
4. HALCON建立相机模型并检查每幅残差；
5. 保存相机序列号、镜头、光圈、WD和报告。

### E2. 图像到机器 XY

1. 靶标置于真实 PCB 高度；
2. 用 5×5 或 7×7 网格覆盖全视野；
3. 从相同方向接近每点；
4. 记录 (row,column,X,Y)；
5. 一部分点拟合，至少20%独立验证；
6. 检查RMSE和最大误差，并画全视野误差方向。

### E3. 上视针尖和TCP

1. 针排移到上视工位；
2. 检测每根针；
3. 计算中心、θ、节距和直线度；
4. 建立上视相机到机器坐标；
5. 保存针排ID、装夹次数和TCP；
6. 换针、碰撞后强制复核。

### E4. T轴

在多个角度拍固定靶，分别正转和反转，拟合真实旋转中心、偏心和回差。

### E5. Z和视差

在PCB高度最小、额定、最大三个平面验证。超预算时应改远心镜头、增加测高补偿、缩小FOV或改进夹具。

## F. 软件联调 SOP

1. 用 mock 后端验证协议；
2. 模拟 BUSY、超时、非法JSON、断网和重连；
3. 用`halcon`后端验证`halcondotnet.dll`、HALCON Runtime和C#视觉流水线；
4. 接文件图像，验证算法和追溯；
5. 最后接真实相机和硬触发；
6. 每个请求使用唯一 requestId；
7. 视觉NG时PLC绝不执行补偿；
8. 超限、相机掉线和标定失效锁存故障。

## G. 验收 SOP

### G1. 视觉重复性

固定件不动拍100次，统计X/Y/θ平均、3σ和范围。

### G2. 全视野准确度

使用计量靶/CMM真值，中心、四角和独立点验证。规划目标可设映射RMSE不大于0.010 mm、最大值不大于0.015~0.020 mm，最终按误差预算确认。

### G3. 机构再现性

每次移开再回来拍100次，覆盖正反方向、不同速度和停稳时间。

### G4. 换装再现性

拆装PCB夹具和针排，跨操作者、跨班次测试。

### G5. 温漂

冷机、热机和环境温度上下限验证黄金样件与坐标残差。

### G6. 端到端

先用钝头针/量规板干运行，再真实插入。用显微镜或CMM测针尖与孔中心，记录力-位移、损伤和电气结果。最终覆盖多个班次、3批PCB和工具磨损状态。

## H. 量产开机 SOP

1. 检查镜头、光源、相机和夹具无松动/污染；
2. 启动视觉服务并确认 ready；
3. 加载正确配方并核对版本；
4. 黄金样件拍10次；
5. 检查均值、范围、亮度和标定有效；
6. 上视检查针排；
7. 低速首件插入，检查力曲线和最终位置；
8. 首件确认后转自动。

任一项失败禁止旁路生产。

## I. 换型 SOP

1. 停机并进入安全状态；
2. 更换夹具、针排、配方；
3. 核对产品和配方版本；
4. 完成针尖TCP复核；
5. 必要时重做XY/T/Z标定；
6. 黄金样件与首件确认；
7. 保存换型记录。

## J. 异常处理

| 异常 | 立即处理 |
|---|---|
| TARGET_NOT_FOUND | 保存原图，检查产品、ROI、光源、污染和遮挡 |
| LOW_SCORE | 禁止运动，检查焦点、光照和目标损伤 |
| CALIBRATION_INVALID | 停产，检查支架和标定版本，复核/重标 |
| CORRECTION_OUT_OF_RANGE | 检查夹具、产品方向、轴坐标和配方 |
| CAMERA_OFFLINE | 检查供电、网线、IP、采集接口和触发 |
| TIMEOUT | 检查到位信号、硬触发、曝光和网络 |
| 插入力异常 | 立即退针/停机，检查弯针、孔偏、Z和板翘 |

不要通过放宽阈值掩盖机械或光学故障。

## K. 维护周期

- 每日：清洁与黄金样件；
- 每班/每批：亮度趋势、重复性趋势；
- 换针/碰撞：上视TCP与T轴复核；
- 每月或按风险：全视野独立点检查；
- 相机/镜头/支架拆装：完整重标；
- 软件/配方变更：离线回归、版本审批、首件验证。

## L. 教学骨架升级到真实设备的任务单

1. 冻结 FOV、针排跨度、孔/针尺寸和节拍；
2. 做样件光源 DOE；
3. 确定相机、远心镜头、光源和滤镜；
4. 安装 HALCON Acquisition Interface；
5. 编写板端和针端采集过程；
6. 用真实图替换合成图并优化孔位定位；
7. 增加逐针检测过程；
8. 完成内参、下视XY、上视TCP、T轴和Z标定；
9. 把真实过程接入 `inspect_pin_row.hdvp`；
10. 按 G 节完成端到端验收。
