# PCB 弹性钢针插入视觉项目：需求与系统架构

## 1. 项目边界

目标工艺是一排带回弹结构的钢针，在 `X/Y/Z/T` 四轴机构带动下插入 PCB 的孔、焊盘或 PIN 对应位置。本文把 `T` 定义为绕 Z 轴旋转的 `θ`。若 T 是绕 X/Y 的倾斜轴，二维方案不适用。

当前已知条件：

- 相机到 PCB 的机械距离约 `200 mm`；这不是镜头的有效工作距离定义，选型时必须确认是物面到镜头前端还是物面到传感器。
- 最终针尖相对目标的平面位置误差要求不超过 `0.05 mm`。
- 上位机只通过 TCP Socket 发送触发请求并接收结果。
- HALCON 负责采图、标定、定位、坐标变换、判定和结果图保存。

当前未知且必须用真实图纸和样件冻结的参数见本文第 9 节。工程配置在 `config/vision.recipe.json`，其中硬件参数仍为占位值。

## 2. 先纠正一个关键认识

九点标定只是二维坐标链的一部分。它拟合从图像 `(row, column)` 到机器 `(X, Y)` 的映射，不能自动解决：

- 镜头畸变；
- PCB 高度变化造成的视差；
- T 轴真实旋转中心和偏心；
- 相机与针尖 TCP 的偏置；
- 针排重装、单针弯曲、针距误差和回弹；
- PCB 翘曲、夹具重复性、机构反向间隙和热漂移。

因此，量产项目必须把相机内参标定、世界平面映射、工具针尖标定、T 轴标定、Z 测高和端到端能力验证串成完整坐标链。

## 3. 推荐硬件架构

推荐采用两套二维视觉和一套独立测高：

1. **下视 PCB 相机**：识别实际孔位或孔位附近的局部基准，输出板端目标的 `X/Y/θ`。
2. **上视针尖相机**：Z 轴把针排移到固定拍照位，检测每根针尖，输出针排实际 `X/Y/θ`，并检查缺针、弯针、节距、直线度。
3. **测高传感器**：激光三角、色散共焦或接触式测高，处理 PCB 翘曲和 Z 基准。二维相机不应承担 Z 精度承诺。
4. **力-位移监控**：插入时记录力曲线；视觉定位正确不代表插入力一定正常。
5. **顺应机构/导向梳**：一排针同时插入属于过约束工艺，建议有微量 XYT 浮动或机械导向。

只用一台下视相机也能做原型，但针排装配和弯曲误差将完全由机械承担，不建议直接承诺 `0.05 mm` 的量产能力。

## 4. 软件架构

```text
PLC / 运动控制器
  ├─ 轴运动、到位、硬件触发、光源频闪、Z/力控（实时层）
  └─ 设备上位机（C#）
       └─ TCP NDJSON: PING / STATUS / TRIGGER / RESET
            └─ Vision.Service
                 ├─ 请求校验、单工位状态机、超时、错误码
                 ├─ 配方、日志、原图与结果留档
                 └─ HalconDotNet / HOperatorSet
                      ├─ 相机采集
                      ├─ PCB / 针尖定位
                      ├─ 标定与坐标变换
                      └─ 质量判定
```

Windows Socket 不是实时总线。正确时序是运动控制器完成定位并发出“到位”，相机使用硬件 I/O 触发曝光；Socket 负责业务请求和结果，不负责微秒级同步。

## 5. 坐标系和变换链

统一使用右手坐标系并在图纸上画明方向：

- `{I_b}`：下视相机图像坐标，HALCON 顺序为 `(row, column)`，即 `(v, u)`。
- `{I_t}`：上视针尖相机图像坐标。
- `{M}`：机器基坐标 `(X, Y, Z, θ)`。
- `{B}`：PCB 局部坐标。
- `{P}`：针排/工具 TCP 坐标。

图像坐标不能直接与机器坐标相减。目标补偿采用二维齐次变换：

```text
T_correction = T_machine_board_target * inverse(T_machine_tool_tip)
```

程序输出的是“建议补偿量”，运动控制器必须做软限位、碰撞区和轴到位检查后才允许运动。

## 6. 生产流程

1. 开机自检：相机、光源、测高、标定文件版本和磁盘空间。
2. 黄金样件复核：固定目标拍摄，残差超限则禁止自动运行。
3. 上视针尖检查：换工具、碰撞后、开班和按周期执行。
4. PCB 到位并夹紧；测量局部 Z 高度。
5. 运动控制器到拍照位置并停止振动。
6. 硬件触发下视相机和频闪光源。
7. HALCON 定位局部目标，转换到机器坐标并计算 `X/Y/θ` 补偿。
8. 视觉服务检查得分、数量、残差和补偿限值，返回 OK/NG。
9. 运动控制器执行补偿和插入；采集力-位移曲线。
10. 保存请求、配方版本、标定版本、原图/结果图、视觉值、轴实际值和最终工艺判定。

## 7. 安全与失败策略

- 视觉服务一次只处理一个 `TRIGGER`；忙碌时返回 `BUSY`，不得并发操作同一相机。
- `requestId` 用于去重和追溯；同一编号不得表示两个不同零件。
- 超过位移、角度、标定残差或匹配得分门限，返回 NG，不输出可执行运动。
- 图像缺失、相机掉线、过曝、欠曝、目标数量错误均为可追溯错误码。
- `RESET` 只清除可恢复的软件故障，不能越过急停、门禁、轴报警和标定失效。
- 所有机械动作最终由 PLC/运动控制器批准，视觉服务绝不直接绕过安全链。

## 8. `0.05 mm` 的精度口径

在签字前必须明确 `0.05 mm` 是：

- 单轴 `±0.05 mm`；
- 径向误差 `sqrt(dx²+dy²) <= 0.05 mm`；
- 最大误差、3σ、还是制程能力要求；
- 仅视觉重复性，还是包含机构、夹具、针变形和 PCB 制造误差的最终误差。

本工程按更严格的“针尖相对目标的径向最大误差 `<=0.05 mm`”做设计预算，但这只是设计目标，必须通过端到端量测验收。

## 9. 冻结方案前必须补齐的数据

| 类别 | 必要输入 |
|---|---|
| 产品 | 针径、孔径/槽宽、配合间隙、针数、节距、针排总长、针尖倒角 |
| PCB | 目标是通孔/焊盘/PIN、板厚、翘曲、绿油与金属表面、基准到孔的套准误差 |
| 视野 | 单次必须覆盖的 X/Y 范围、最小特征尺寸、可否分区拍摄 |
| 节拍 | 每片允许拍摄和计算时间、运动中还是停稳拍摄 |
| 结构 | 200 mm 距离的定义、镜头外径/长度空间、光源安装空间、目标遮挡关系 |
| 运动 | XYT 重复定位、反向间隙、正交度、T 轴偏心、编码器分辨率、温漂 |
| 工艺 | 允许插入力、侧向力、压缩量、板和针的损伤极限、换型方式 |
| 质量 | 公差统计口径、Cpk 目标、量测基准、GR&R 方法、追溯保存期 |
