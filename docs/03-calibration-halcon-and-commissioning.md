# HALCON 标定、定位与现场调试

## 1. HALCON 学习主线

建议按生产数据流学习，而不是按算子字典顺序学习：

1. `read_image`、`get_image_size`、ROI 与域；
2. 阈值、形态学和连通域：`threshold`、`connection`、`opening_circle`、`select_shape`；
3. 亚像素轮廓与几何拟合：`edges_sub_pix`、`fit_circle_contour_xld`、`fit_line_contour_xld`；
4. 形状模板：`create_shape_model`、`find_shape_model`，理解分数、角度范围、金字塔层级；
5. 二维变换：`vector_to_hom_mat2d`、`affine_trans_point_2d`、`hom_mat2d_*`；
6. 相机标定：标定板、相机参数、畸变、世界平面与 `image_points_to_world_plane`；
7. HalconDotNet：正式C#服务直接调用`HOperatorSet`，`.hdev/.hdvp`保留为算法原型参考；
8. 图像采集、硬触发、异常恢复和结果留档。

本工程的 `.hdvp` 文件是外部过程，可直接在 HDevelop 中打开；`offline_production_demo.hdev` 用合成数据演示完整闭环，不需要相机。

## 2. 九点/多点二维标定

### 数据采集

1. 将高精度十字、圆靶或针尖移动到实际 PCB 高度。
2. 让运动点覆盖完整工作视野，不要只聚在中心。
3. 每个点只从同一运动方向逼近，或明确测量反向间隙。
4. 记录 HALCON 图像坐标 `(row, column)` 和机器反馈值 `(X, Y)`。
5. 采集至少 `5×5` 网格；九点可用于入门，但量产应保留未参与拟合的验证点。

`config/nine-point.sample.csv` 给出了 9 个拟合点和 2 个独立验证点的字段格式。

### 拟合与验证

二维仿射模型包含平移、旋转、尺度、非正交和剪切，可写为：

```text
X = a*column + b*row + c
Y = d*column + e*row + f
```

HALCON 中使用 `vector_to_hom_mat2d` 拟合，并用 `affine_trans_point_2d` 回代。每个点的残差为：

```text
error_i = sqrt((X_fit-X_measured)^2 + (Y_fit-Y_measured)^2)
RMSE = sqrt(mean(error_i^2))
```

规划门槛：拟合 RMSE `<=0.010 mm`、全视野独立验证点最大残差 `<=0.015~0.020 mm`。这不是最终产品误差，只是坐标映射的子预算。

### 为什么还要做相机内参标定

仿射模型不能完整描述普通镜头径向畸变。量产流程应先用高精度玻璃标定板估计相机内参和畸变，再在实际工作平面建立到机器坐标的关系。若使用远心镜头，也要用 HALCON 对应的远心相机模型进行验证，不要假设“远心即零畸变”。

## 3. T 轴和工具 TCP 标定

1. 在多个 T 角度拍摄固定标准靶，拟合真实旋转中心。
2. 分别测试正转和反转，识别回差和方向相关误差。
3. 上视相机检测每根针尖，计算针排中心线、平均节距和端点角度。
4. 建立 `{M}` 到针尖 TCP 的变换，而不是只标定安装座。
5. 换针排、碰撞、维修后强制重做或复核。

仅用整体模板定位针座会漏掉单针弯曲。量产应输出每根针的中心、节距偏差、到拟合直线距离和缺针状态。

## 4. PCB 目标定位策略

优先顺序：

1. 直接检测实际要插入的孔/PIN；
2. 检测目标附近的局部基准；
3. 最后才使用距离很远的 PCB 全局基准。

原因是 PCB 制造中“全局基准到实际孔”的套准误差可能已经接近总公差。孔有稳定背光时，可采用轮廓/区域加圆拟合；反射目标可使用边缘、形状模型或局部几何组合。

一个稳健的检测过程应包含：

- 固定 ROI；
- 曝光/平均灰度健康检查；
- 候选提取；
- 面积、圆度、半径、间距和数量约束；
- 亚像素边缘拟合；
- 几何一致性检查；
- 结果分数和失败原因，而非只返回一个点。

## 5. 误差预算示例

| 误差项 | 设计目标 |
|---|---:|
| PCB 特征定位 | 0.006 mm |
| 针尖定位 | 0.006 mm |
| 内参与畸变残差 | 0.008 mm |
| 图像到机器坐标、T 中心 | 0.010 mm |
| XYT 轴重复定位 | 0.015 mm |
| 高度、视差和热漂移 | 0.008 mm |
| 插入力、弹性与结构变形 | 0.020 mm |

若这些是相互独立的随机项，RSS 约 `0.030 mm`；再给系统偏差预留约 `0.010 mm`，设计目标约 `0.040 mm`。系统性偏差不能通过 RSS 抵消，最终仍须端到端量测。

## 6. 调试 SOP

### 阶段 A：离线算法

1. 收集至少 3 批 PCB、良品/缺陷、污染、氧化、不同反光状态的原图。
2. 图像命名包含产品、批次、工位、曝光、光源、结果和时间。
3. 在 HDevelop 中固定随机性和参数，禁止只挑“最好看”的图。
4. 建立回归集，每次修改后统计漏检、误检、定位均值和标准差。

### 阶段 B：单相机重复性

固定标准件不动连续拍摄 100 次：

- 记录 X/Y/θ、得分、耗时和灰度；
- 检查均值漂移、`3σ`、最大最小值；
- 改变曝光、环境光和温度验证稳定性。

### 阶段 C：坐标映射

- 使用计量级玻璃靶或 CMM 标定件；
- 覆盖全视野并保留独立验证点；
- 分别统计拟合点和验证点，不得只报告 RMSE；
- 检查中心/四角、高低 Z 和正反运动方向。

### 阶段 D：端到端干运行

- 使用钝头标准针和量规板，先禁止真正插入；
- 视觉给出补偿，机构移动后用显微镜/CMM 量测残差；
- 验证碰撞区、软限位、超差 NG、相机掉线、超时和重连。

### 阶段 E：工艺能力

- 至少多个班次、3 批 PCB、多个针排装夹状态和数百次循环；
- 测量针尖到孔中心误差、插入力曲线、针/板损伤与电气结果；
- 若图纸要求每轴公差，分别算能力；若是径向上限，不能拆成两个独立的 `±0.05 mm`；
- 建议关键尺寸 `Cpk >= 1.67`，并先确认量测系统 GR&R 合格。

## 7. 开机与维护规则

- 每次开机：黄金样件验证；
- 每班：固定目标重复性检查；
- 换工具、碰撞或维修：针尖 TCP 与 T 中心复核；
- 相机/镜头/支架松动：完整重标定；
- 温度跨越验证范围：禁止生产或重新热机验证；
- 标定文件包含设备编号、相机序列号、镜头、配方、日期、操作者和残差报告，禁止无版本覆盖。

## 8. 本机 HALCON 环境说明

本机已安装 HALCON `23.11 Progress x64`。工程通过`halcondotnet.dll`直接调用HALCON算子，生产机需要正确的HALCON Runtime授权。接GigE/USB3真相机前，应从MVTec安装与相机协议匹配的Acquisition Interface，并用`info_framegrabber`验证接口和参数。
