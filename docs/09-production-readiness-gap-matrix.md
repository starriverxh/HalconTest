# 钢针插 PCB 视觉系统：量产就绪缺口矩阵

## 1. 结论先行

当前项目是 **S1：可运行的离线视觉工程工作台**，不是已经通过设备验收的量产系统。

```text
S0  算法样例       单张图能跑
S1  工程工作台     能调参、保存模型/标定、配方驱动离线检测   ← 当前
S2  设备试生产     真实相机/运动/IO闭环，完成重复性和异常测试
S3  量产批准       GR&R、能力、节拍、追溯、安全和变更流程全部签字
```

没有真实相机、镜头、光源、针排相机、运动控制器、PCB/针排样件和测量基准时，任何软件都不能
证明“误差不超过 0.05 mm”。软件只能先把接口、算法生命周期、配方和验证框架做好。

## 3. 0.05 mm 不能只看算法输出

建议把总误差按 RSS（均方根合成）管理，而不是让每个环节都使用 0.05 mm：

```text
E_total² ≈ E_optics² + E_feature² + E_calibration² + E_motion²
         + E_rotation² + E_height² + E_tool² + E_repeatability²
```

示例目标分配（必须由实测修订）：

| 误差项 | 初始目标 |
|---|---:|
| 光学/特征重复性 | ≤ 0.010 mm |
| 相机到机械标定 | ≤ 0.015 mm |
| 运动重复定位 | ≤ 0.015 mm |
| T轴旋转中心/回差 | ≤ 0.015 mm |
| PCB高度/翘曲 | ≤ 0.010 mm |
| 针排定位和弹性 | ≤ 0.020 mm |

这些数值平方后合成才有机会留出安全余量。若单像素对应 0.03 mm，即使亚像素算法看起来能输出很多小数，
也不代表现场稳定精度足够。因此相机选型必须先知道实际 FOV，不是仅凭 200 mm 工作距离选型号。

## 4. 正确的量产算法链

```text
硬触发采图
  → 图像质量检查（亮度/饱和/清晰度/丢帧）
  → 产品粗定位（Shape Model）
  → 生成位姿变换并让检测 ROI 跟随产品
  → PCB孔/Mark精定位（Blob或亚像素轮廓）
  → 像素去畸变
  → camera→machine 坐标变换
  → 针排相机独立定位每根针
  → PCB位姿与针排位姿在同一机械坐标系比较
  → XYT补偿 + Z插入前质量/安全判定
  → PLC范围和互锁二次确认
  → 保存可追溯结果
```

当前工程已实现其中的离线 PCB 定位、配方 ROI、Blob/ShapeModel 二选一、仿射坐标变换和结果保存；
未实现的节点必须保持显式，不允许用固定常数冒充真实测量。

## 5. 下一阶段按门禁推进

### Gate A：离线算法冻结

- 收集真实 OK、边界和 NG 图片；
- 建黄金标签和批量回归工具；
- 冻结 ROI、模板、阈值、分数和运行时间上限；
- 所有失败返回明确工艺错误码。

### Gate B：单相机设备闭环

- 接 PCB 下视相机和硬触发；
- 完成内参/畸变、平面标定和 T 轴旋转中心；
- 固定件 100 次重复，随机位置独立验证；
- PLC 完成状态机、对账和安全互锁。

### Gate C：双相机针排闭环

- 接上视针相机；
- 检查每根针的中心、节距、直线度、缺针和弯针；
- 统一 PCB/针排/工具/平台坐标链；
- 多高度、多角度、正反向运动验证。

### Gate D：量产批准

- GR&R、Cmk/Cpk、节拍、72h/168h稳定性；
- 光照衰减、温漂、断网、磁盘满、进程崩溃等故障注入；
- 配方审批/回滚、权限、审计和追溯验收；
- 机械、电气、视觉、工艺和质量共同签字。
