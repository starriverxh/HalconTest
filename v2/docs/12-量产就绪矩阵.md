# 量产就绪矩阵

本页只回答一个问题：当前仓库里究竟有什么证据。不要把“类名存在”“页面能打开”或“合成图通过”自动解释成量产能力。

三栏含义：

- `已真实实现（当前软件）`：源码确实执行，并有相应测试或离线运行证据；只证明软件行为。
- `教学/离线演示`：用于学习原理或走通软件链，输入、数值或界面仍是合成/内存数据。
- `待硬件/量产`：必须用真实相机、运动、样件、量具或正式发布流程取得证据；标有“阻断量产”的项目未关闭前，`ProductionCommissioned` 必须保持 `false`。

## 文件事实核对

- 当前不存在 `v2/packages/` 发布包目录。
- `Vision.Infrastructure` 中存在 SHA-256 验证和活动索引仓储源码及单元测试，但当前 `Vision.Runtime` 装配的是 `JsonRecipeRepository`，直接读取 `config/recipes/*.json`。
- 当前不存在可发布的 PCB `.shm`；只有 Shape Model 元数据示例。默认离线配方使用 `BlobRow`。
- WPF ROI 画布显示合成 PCB，ROI 草稿不写配方，也不传入 `Vision.Halcon`。
- WPF 模板、标定、配方、回归和追溯主要使用教学 Gateway；生产页的离线检测按钮才连接 9201 Runtime。
- 当前数据集是正常、缺针、弯针三例合成图，没有真实位置真值、批次统计或 locked-acceptance 集。

## 当前发布级别

```text
Software level     : V2 Engineering Offline
Commissioning state: Uncommissioned
Normal offline result: EngineeringOnly
MotionAllowed      : false
```

只有所有“阻断量产”项目都取得经责任人签字的真实证据，并完成不可变工位快照和故障安全评审，才允许启用生产检测。通过合成测试、手工把配方状态改为 Published，或在 UI 中显示四位小数，都不能关闭这些门禁。
