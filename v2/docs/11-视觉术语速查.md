# 视觉术语速查

| 术语 | 含义 | 在本项目中的位置 |
|---|---|---|
| FOV | 物方视野宽高 | 决定分辨率和镜头倍率，不能由 WD 代替 |
| WD | 镜头到物体的工作距离 | 当前机械约束约 200 mm，仍需结合镜头定义 |
| DOF | 景深 | 必须覆盖 PCB 翘曲和针尖高度变化 |
| Pixel Size | 传感器像元尺寸 | 与镜头倍率共同决定物方采样 |
| Object-space sampling | 物方像素当量 mm/px | `FOV / pixels` |
| Global Shutter | 全局快门 | 全画面同时曝光，适合运动/硬触发 |
| Telecentric Lens | 远心镜头 | 降低高度变化导致的放大率/视差变化 |
| MTF | 调制传递函数 | 镜头对不同空间频率的对比传递能力 |
| Backlight | 背光 | 获得孔/针稳定轮廓的优选照明 |
| Coaxial Light | 同轴光 | 光线沿镜头轴入射，适合平面反射特征 |
| Dome Light | 穹顶漫射 | 从多方向均匀照明，压低方向性反光 |
| ROI | 感兴趣区域 | 命名、版本化，可跟随产品姿态 |
| Blob | 连通区域及面积/重心等特征 | 可用于候选筛选，不直接等同亚像素精度 |
| Region | HALCON 面域对象 | 阈值、形态学、连通域处理常用 |
| XLD | 亚像素轮廓对象 | `edges_sub_pix`、圆/线拟合使用 |
| Shape Model | 基于边缘形状的模板 | 负责粗定位和 ROI 跟随 |
| Model Origin | 模板返回位姿的参考原点 | 必须绑定 PCB CAD 基准 |
| Score | 匹配/特征置信指标 | 不是毫米精度，也不同于 Blob 圆度 |
| Pyramid Levels | 金字塔层级 | 加速大范围匹配，但可能丢小特征 |
| Contrast/MinContrast | 形状模型边缘阈值 | 决定哪些轮廓进入/参与匹配 |
| Greediness | 搜索速度与完整性的折中 | 越高不等于越准确 |
| Subpixel | 亚像素测量 | 通过灰度/边缘模型在像素间估计位置 |
| Metrology Model | HALCON 计量模型 | 沿测量条提取边缘并拟合圆/线等几何 |
| Calibration Intrinsics | 相机内参 | 焦距、主点、像素尺寸、畸变等 |
| Extrinsics | 相机外参 | 相机相对世界/工作平面的姿态 |
| Radial Distortion | 径向畸变 | 普通镜头中心/边缘放大率差异之一 |
| Reprojection Error | 重投影误差 | 标定模型把世界/图像点来回映射的残差 |
| Affine Transform | 仿射变换 | 平移、旋转、缩放、剪切，不能完整表示透视/径向畸变 |
| Homography | 平面单应性 | 两个平面投影之间的 3×3 变换 |
| Nine-point Mapping | 九点/多点平面映射 | 像素到机器 XY；不是完整相机内参标定 |
| Hand-eye Calibration | 手眼标定 | 相机跟随运动头时连接相机、法兰和机器坐标 |
| Coordinate Frame | 坐标系 | `{I}/{C}/{M}/{F}/{B}/{P}` 必须明确 |
| Pose2D / SE(2) | 二维刚体位姿 | X、Y、Theta 及其非交换组合 |
| Rigid Registration | 刚体配准 | 通过 N 对针孔点求 R、t |
| Residual | 残差 | 对齐后预测点与目标点的距离 |
| RMSE | 均方根误差 | 总体误差统计；不能代替最大单针残差 |
| T-axis Pivot | T 轴旋转中心 | 旋转引起 XY 耦合，必须单独标定 |
| Backlash | 回差 | CW/CCW 或正反向运动的系统差异 |
| Repeatability | 重复性 | 同一条件反复测量的离散 |
| Accuracy/Bias | 准确度/偏倚 | 测量均值相对独立真值的差 |
| GR&R | 量具重复性与再现性 | 衡量测量系统相对公差的贡献 |
| Cmk/Cpk | 设备/过程能力指数 | 长期分布相对规格，不由单张图产生 |
| False Accept | 错误放行/漏检 | NG 被判 OK，插针工艺风险最高 |
| False Reject | 误杀 | OK 被判 NG，影响产能和维护 |
| Idempotency | 幂等 | 同一 requestId 重发不再次采图/执行 |
| Recipe | 产品配方 | 产品相关 ROI、模板、名义点、参数和判定 |
| Calibration Package | 工位标定包 | 设备相关相机、平面、T 中心和工具关系 |
| Runtime Snapshot | 运行快照 | 本周期精确绑定的配方/标定/硬件/算法版本 |
| Commissioning | 调试验收 | 从离线到真实硬件并取得运动许可的过程 |
| Traceability | 追溯 | 从结果回到原图、参数、配方、标定和代码版本 |

## HALCON 对象类型

- `HObject`：图像、Region、XLD 等 iconic object 的 C# 容器；必须正确 Dispose。
- `HTuple`：HALCON 控制参数和结果的动态元组；读取数值前检查长度和类型。
- `HImage/HRegion/HXLDCont`：HALCON 面向对象封装类型；项目应统一风格，避免生命周期混乱。
- `HOperatorSet`：C# 直接调用过程式 HALCON 算子的静态入口。
- `HDevEngine`：从 C# 执行 HDevelop 程序/过程的运行引擎；本 V2 正式生产算法不采用此路径。

## 常见误区

- `Score=0.95` 不代表误差 `0.05 mm`；
- `0.01 mm/px` 不代表定位精度一定 `0.01 mm`；
- 九点标定 RMSE 小不代表镜头畸变和 Z 变化已解决；
- 补偿量大不等于对齐残差大；
- 模板找到 PCB 不等于每个孔都合格；
- 针排名义 CAD 点不等于每周期真实针尖；
- UI 显示 OK 不等于设备可以运动，必须检查 `MotionAllowed`；
- 合成图通过不等于真实产品通过。
