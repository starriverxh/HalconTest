# 设备调试与量产导入 SOP

本 SOP 只在真实机械、电气和安全方案确认后执行。未经阶段签字，不允许直接用真实 PCB 做自动插入。

## 阶段 A：机械与安全前置

- [ ] 明确 `{M}/{F}/{B}/{P}` 坐标系和 XY/T 正方向；
- [ ] 明确 T 轴是先旋转后平移还是其他运动顺序；
- [ ] 获取轴分辨率、定位精度、重复性、回差和软限位；
- [ ] 相机支架、镜头、光圈、焦距和工作距离可机械锁定；
- [ ] PCB 夹紧、存在检测、Z 安全位和门禁接入 PLC；
- [ ] 工程点动采用按住运动、低速和软件/硬件限位；
- [ ] 插针前使用无损量规或安全治具。

输出：坐标/运动约定书、安全回路验证记录。

## 阶段 B：光学 DoE 和硬件冻结

1. 根据真实 FOV 计算像素当量；
2. 用真实多批 PCB 和钢针比较候选相机/镜头/光源；
3. 采集中心/四角、Z 高低、偏移/旋转、曝光/光强矩阵；
4. 评估孔边/针边对比度、饱和、清晰度、均匀性和重复性；
5. 确定相机分辨率、全局快门、接口、镜头倍率/WD、远心度和光源；
6. 记录最终硬件序列号和锁定位置。

门禁：全 FOV/景深采样和定位重复性满足预算，真实缺陷可区分。

## 阶段 C：相机接入

每台相机分别验证：

- [ ] Open/Close 100 次无资源泄漏；
- [ ] 单帧、连续、软触发和硬触发行为明确；
- [ ] FrameId 单调且能与 TriggerId 对账；
- [ ] 曝光时间、增益、像素格式和实际回读一致；
- [ ] 超时后不会返回上一帧；
- [ ] 断线重连后重新初始化并阻止旧标定误用；
- [ ] 曝光时轴反馈和时间戳可获得；
- [ ] 连续 8 小时无重复帧、旧帧和缓冲错配。

将 `FileFrameSource` 替换为真实相机适配器，但不要修改上层算法接口。

## 阶段 D：相机内参与工作平面标定

PCB/针排相机分别：

1. 预热相机和光源；
2. 清洁镜头/标定板，确认工作平面 Z；
3. 采集覆盖中心、四角、不同姿态的标定板图；
4. 选择正确相机模型（普通/远心）；
5. 计算内参和畸变；
6. 检查重投影误差和异常图；
7. 建立图像/世界平面到机器坐标关系；
8. 使用独立验证点和随机运动路径验证；
9. 在允许 Z 范围边界检查误差；
10. 保存标定包、原图和硬件指纹。

门禁：独立点通过，而不只是拟合 RMSE 通过。

## 阶段 E：T 轴中心、工具和回差

1. 在安全高度安装稳定视觉靶；
2. 选择覆盖工作范围的多个 T 角度；
3. 每角度重复定位并记录机器 XYT；
4. 拟合旋转轨迹圆心得到 `C_T`；
5. CW、CCW 分开执行，量化回差；
6. 不同半径和 Z 高度重复；
7. 建立工具坐标 `{F}T_P` 和 T 零位；
8. 用未参与拟合的角度验证端点误差。

门禁：旋转中心和回差误差满足预算；控制器命令符号/顺序由独立点验证。

## 阶段 F：真实 PCB/针排算法

- 使用真实训练集创建粗定位模板并设置 CAD 基准原点；
- 每个 PCB 孔建立命名跟随 ROI 和亚像素测量；
- 每根针建立稳定轮廓/尖点算法；
- 验证缺针、弯针、针距、直线度和污染；
- 建立 P1...PN 不歧义的 ID 规则；
- 输出每点拟合残差和置信度；
- 运行独立 validation 和 locked-acceptance 数据集。

门禁：关键 NG 无错误放行，偏差/重复性/耗时达标。

## 阶段 G：双相机闭环但不插入

1. 读取 PCB 真实孔点；
2. 读取针排真实针点；
3. 计算 N 点对齐和逐针预测残差；
4. 检查 T 中心换算后的轴命令；
5. 使用安全量规/透明靶或高精度独立相机验证运动后残差；
6. 随机 XY/T、中心/四角、不同 Z、CW/CCW 重复；
7. 故意制造超安全范围、缺针和互锁打开，确认禁止运动。

门禁：运动后独立测量的每点残差满足预算，所有故障安全停机。

## 阶段 H：低风险插入验证

- 从低速、低加速度、有限力/力矩和软材料样件开始；
- 每次运动前再次确认夹紧、Z 安全和 requestId；
- 记录插入力、最终位置、逐针残差和图像；
- 发生异常立即停止，不用放宽视觉阈值掩盖机械问题；
- 逐步扩大板位、角度、批次和节拍范围。

门禁：工艺、机械、安全、质量联合评审通过。

## 阶段 I：能力和耐久

- 静态 100～1000 帧重复性；
- 多批 PCB/针排、多装夹、多温度；
- GR&R、偏倚、线性、稳定性；
- 8/72/168 小时运行；
- requestId、图像、结果、配方和标定全追溯；
- 内存、HALCON 句柄、磁盘和耗时进入稳定平台；
- 计算适当口径的 Cmk/Cpk。

只有端到端独立测量证明 `≤0.05 mm`，才在配方/工位状态中启用 `ProductionCommissioned=true`。

## 换型 SOP

1. 停止自动运行并确认无活动周期；
2. 选择已 Published/Approved 的目标配方；
3. 校验配方包 SHA-256；
4. 校验工位标定与相机/镜头/分辨率兼容；
5. 加载模板和 ROI；
6. 黄金图 dry-run；
7. 黄金样件/验证点确认；
8. 原子激活新快照；
9. 记录操作者、时间、旧/新版本和哈希；
10. 首件检查并由规定角色放行。

## 标定日常确认

每班/每批按风险确定频率：

- 预热时间完成；
- 镜头、支架和光源无松动/污染；
- 黄金验证靶中心和四角误差在门限内；
- 清晰度、平均灰度和饱和比例在控制区间；
- T 轴验证角端点误差正常；
- 相机序列号、分辨率和活动标定 ID 一致。

失败时标定状态置 Invalid，禁止自动运动；不得只点 Reset 清除。
