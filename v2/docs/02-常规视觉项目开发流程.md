# 常规视觉项目开发流程

工业视觉不是“选一个阈值，能识别一张图，然后接 Socket”。下面是从需求到量产的标准阶段。任一阶段没有证据，就不能用后面漂亮的界面替代。

## G0：需求和工艺冻结

必须收集：

- 针数量、针径上下限、针尖形状、名义针距、总跨度、允许弯曲和短针量；
- PCB 孔径上下限、孔距和位置公差、焊盘/绿油、板厚、翘曲、治具遮挡；
- FOV、允许来料偏移/转角、相机安装空间、工作距离约束；
- 设备节拍、曝光窗口、触发方式、轴运动顺序和反馈接口；
- `0.05 mm` 的统计口径：单轴、径向最大值、3σ，还是运动后每根针孔残差；
- 最小针孔间隙和允许插入力。

输出：经机械、电气、工艺、视觉共同确认的 URS 和风险清单。

门禁：FOV、尺寸、公差和误差定义没有冻结时，不允许下最终相机/镜头订单。

## G1：误差预算

把总误差拆给：PCB 定位、针尖定位、两台相机标定、T 轴中心、工具偏置、运动重复性、回差、夹具、Z 高度、温漂和产品变形。

输出：误差预算表、验证方法和责任人。

门禁：每一项都必须有测量方法；“HALCON 能亚像素”不是误差证据。

## G2：光学可行性实验

使用真实 PCB、真实钢针和候选镜头/光源做 DoE：

- 改变曝光、光强、光源角度、光圈、工作距离和背景；
- 覆盖中心和四角、不同 Z 高度、表面批次和污染；
- 计算像素当量、对比度、饱和比例、重复定位和景深；
- 钢针优先验证轮廓背光，不依赖随角度漂移的高光亮斑。

输出：原始图片包、参数表、选型报告和风险。

门禁：关键边缘在整个 FOV/景深内稳定，采样和重复性满足误差预算。

## G3：建立数据集和真值

数据必须分开：

```text
training/          训练模板、建立初始参数
tuning/            调阈值和鲁棒性
validation/        开发期间回归
locked-acceptance/ 最终冻结验收，算法开发者不能反复偷看调参
```

样本至少包括：正常、边界、缺针、弯针、短针、孔堵塞、污渍、反光、欠曝、过曝、虚焦、偏移、旋转、中心/四角、温度和批次变化。

真值来自 CMM、工具显微镜、计量靶或经确认的量规，而不是算法自己的输出。

## G4：HDevelop 原型

在 HDevelop 中按阶段原型开发，每一步保存并观察中间结果：

```text
采集/读图
→ 图像质量门禁
→ 畸变校正
→ Shape Model粗定位
→ ROI位姿跟随
→ 亚像素孔/针尖精定位
→ 几何排序和编号对应
→ 标定变换
→ 刚体拟合和逐针残差
```

输出：可重复执行的 `.hdev/.hdvp`、参数解释、失败样本和阶段验收数据。

门禁：不能只在训练模板的同一张图上得到高分；必须跑独立样本。

## G5：标定与坐标链

分别完成：

1. PCB 下视相机内参/畸变；
2. PCB 工作平面到机器坐标；
3. 针排上视相机内参/畸变；
4. 针排工作平面到机器/工具坐标；
5. T 轴真实旋转中心；
6. 工具偏置、T 轴零位和正反向回差；
7. Z 高度变化敏感性。

输出：原图、点表、拟合参数、残差矢量、独立验证点和硬件指纹。

门禁：验证点必须独立于拟合点；换相机、镜头、分辨率、焦距、工作距离或安装位置后标定自动失效。

## G6：C# 产品化

把冻结的算子流程实现到 `Vision.Halcon`，但保留 HDevelop 学习原型。C# 版本需要增加原型阶段通常没有的内容：

- 原生句柄生命周期；
- 缓存模型，不在每帧重建；
- 明确失败码和阶段耗时；
- 配方范围校验；
- 状态机和超时；
- 日志、原图和版本追溯；
- 数据集自动回归。

门禁：相同输入和相同版本产生容差内确定结果；循环运行后内存和句柄稳定。

## G7：工程站、ROI、模板和配方

工程站必须支持：命名 ROI、ROI 跟随、模板原点、模板多样本验证、标定向导、配方草稿、差异比较、回归报告、审批、激活和回滚。

任何 UI 修改先进入 Draft，不能直接改变 Active 生产版本。

## G8：协议与设备集成

完成真实相机硬触发、帧 ID、曝光时间、轴位置快照、PLC requestId/cycleId 对账、超时、重复包、断线恢复、磁盘不足和安全互锁测试。

门禁：重复 `requestId` 不能再次触发；产品 NG 不导致系统 Fault；相机旧帧和轴未静止必须阻止运动。

## G9：测量系统分析和端到端验收

先使用安全量规/仿真治具，不直接插真实 PCB。按随机 XYT、正反向 T、中心/四角、多高度、多批次、多温度运行：

- 静态定位重复性；
- 对独立真值的偏差；
- 运动后残余误差；
- GR&R；
- Cmk/Cpk；
- 8/72/168 小时稳定性；
- 最终插入力和插入成功率。

只有端到端实际每针残差满足定义，才能声明达到 0.05 mm。

## G10：量产和持续维护

- 发布包不可修改；任何参数变化生成新版本；
- 标定和硬件变更形成审计记录；
- 每次生产结果绑定精确的配方、模板、标定和算法哈希；
- 定期用黄金样件和验证点检查漂移；
- 通过控制图监测分数、残差、曝光、清晰度和耗时趋势；
- 回滚不删除旧记录。

项目不是在第一次 OK 时完成，而是在异常能被稳定检测、版本能被追溯、设备能安全恢复时才接近量产。
