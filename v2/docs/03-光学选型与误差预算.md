# 光学选型与误差预算

## 为什么“相机距离 PCB 200 mm”还不能选型

工作距离只说明镜头前端到物体的大致空间。相机和镜头至少还需要这些输入：

- 整排针/PCB 需要看到的实际宽高，即 FOV；
- 最小孔径、针径和希望测量的最小缺陷；
- PCB 翘曲和针尖 Z 高度范围；
- 允许曝光时间和节拍；
- 安装空间、接口带宽、预算；
- 是否能在孔后面放背光；
- 相机是否固定，还是跟随 XY/T 轴移动。

所以本项目把硬件选型做成计算流程，不把某个型号写死成“正确答案”。

## 第一步：由 FOV 和像素当量反推分辨率

物方像素当量：

```text
sx = FOV宽度(mm) / 图像宽度(px)
sy = FOV高度(mm) / 图像高度(px)
```

对于总误差 `≤0.05 mm` 的项目，初始设计通常希望物方采样约 `0.010～0.015 mm/px`，关键圆或针宽至少有 `20～30 px`。这只是设计起点，最终仍需实测。

假设（仅作计算示例）整排长度 60 mm，加上定位和来料偏移后需要 `80 × 45 mm` FOV：

| 相机水平像素 | 80 mm FOV 的像素当量 | 评价 |
|---:|---:|---|
| 2448 px | 0.0327 mm/px | 对 0.05 mm 总目标余量很小 |
| 4096 px | 0.0195 mm/px | 可做可行性实验，仍需严格误差验证 |
| 5120 px | 0.0156 mm/px | 接近初始设计范围 |
| 8192 px | 0.0098 mm/px | 采样更充足，但成本、带宽和镜头要求高 |

不能简单说“亚像素能到 0.1 像素，所以低分辨率也行”。亚像素精度依赖边缘对比度、PSF、噪声、反光、景深、标定和模型偏差。

## 第二步：检查针孔间隙

单根针允许的理论径向偏心上限：

```text
e_clearance = (最小孔径 - 最大针径) / 2
```

工程安全残差：

```text
e_allowed = min(0.05 mm, e_clearance - 毛刺/弯针/装配安全余量)
```

例如最小孔径 `1.00 mm`、最大针径 `0.90 mm`，理论单边间隙只有 `0.05 mm`。再扣除毛刺和针变形后，视觉与运动的允许残差一定小于 0.05 mm，不能仍把 0.05 当作宽松门限。

## 第三步：由针排长度反推角度容差

角度误差在针排端部产生横向偏差：

```text
eθ ≈ L · |θ|
```

其中 `L` 是从旋转参考中心到最远针的距离，`θ` 使用弧度。若总跨度 60 mm，最远针约 30 mm，希望角度造成的端点误差不超过 0.02 mm：

```text
θmax = 0.02 / 30 = 0.000667 rad ≈ 0.0382°
```

所以配方里的角度限值必须由几何反推，不能脱离针排长度随意写 `0.05°`。

## 推荐的两相机方向

### PCB 下视相机

- 黑白、全局快门面阵相机；
- 分辨率由真实 FOV 计算，优先保证采样而不是追求高帧率；
- 触发模式必须支持硬触发、帧 ID 和曝光完成时间；
- 若 PCB 翘曲和透视要求高，优先评估双远心/物方远心镜头；
- 普通低畸变镜头可以作为成本方案，但必须做内参、畸变、Z 高度和全 FOV 验证。

光源优先级：

1. 通孔后方能布置时，漫射背光最容易获得稳定孔轮廓；
2. 不能背光时，评估同轴光 + 穹顶漫射，压低焊盘和绿油方向性反光；
3. 必要时增加低角度分区光，用不同通道分别突出孔边和污染；
4. 光源必须频闪/恒流受控，并回读实际亮度或电流。

### 针排上视相机

- 黑白、全局快门；
- 固定安装时应建立上视相机到机器/工具坐标的独立标定；
- 优先远心镜头，减少针尖高度变化带来的放大率变化；
- 优先轮廓背光，让钢针成为稳定剪影；
- 不要把金属表面的高光亮点当针尖中心，高光会随角度、氧化和光强移动。

2D 上视只能可靠判断平面位置和部分轮廓。若短针、针尖高度和 Z 方向弯曲也是关键质量项，需要侧相机、激光位移或 3D 方案。

## 镜头初算

普通镜头近似放大率：

```text
M = 传感器宽度 / FOV宽度
```

若传感器宽 17.6 mm，FOV 宽 80 mm：

```text
M ≈ 0.22×
```

远心镜头应选择接近该倍率、覆盖传感器尺寸、工作距离接近 200 mm 且畸变/远心度满足预算的型号。普通镜头可用薄透镜初算焦距，但最终必须用厂商视野计算器和实拍确认；机械工作距离不等于镜头参数表中的物方工作距离定义。

同时检查：

- 镜头解析力能覆盖传感器像元，不出现“高像素配低 MTF 镜头”；
- 景深覆盖 PCB 翘曲和针尖高度；
- 光圈关闭增加景深时，衍射不会吞掉边缘；
- 镜头畸变、远心度、CRA、暗角和照明均匀性；
- 相机传感器尺寸与镜头成像圈；
- 安装后焦距、光圈、对焦环必须机械锁紧。

## 带宽和曝光检查

单帧原始数据近似：

```text
bytes/frame = width × height × bitsPerPixel / 8
bandwidth = bytes/frame × frameRate
```

例如 8192 × 5468、Mono8 单帧约 44.8 MB。即使每周期只拍一张，也要检查接口传输时间、缓存、磁盘写入和 UI 显示降采样。视觉测量使用原图，UI 可以显示缩略图，不能反过来用缩略图测量。

运动中硬触发还需检查拖影：

```text
物方拖影 ≈ 曝光时间 × 物方速度
```

要么轴停稳后曝光，要么把拖影分配到小于允许像素误差，并用硬件时间戳同步轴反馈。

## 示例误差预算（设计分配，不是验收结果）

| 误差源 | 初始设计目标（径向或等效，mm） | 验证手段 |
|---|---:|---|
| PCB 孔精定位 | 0.010 | 计量靶/显微真值，中心与四角 |
| 针尖精定位 | 0.010 | 计量靶/工具显微镜 |
| 两相机平面映射组合 | 0.012 | 独立验证点，不参与拟合 |
| T 轴中心与角度耦合 | 0.010 | 多角度圆拟合、CW/CCW |
| XY/T 运动重复性 | 0.015 | 激光/编码器/量规重复运动 |
| 夹具、温漂和短期机械变化 | 0.010 | 多温度、多装夹、长稳 |

上述值按 RSS 约为 `0.028 mm`，给端到端 0.05 mm 留出剩余空间。但误差并不总是独立高斯分布，系统偏差必须单独校正，最坏情况也必须验证。

建议离线和调试阶段先把“补偿后预测最大单针残差”门限设到约 `0.020～0.025 mm`，再由真实针孔间隙和完整误差预算确认。

## 采购前必须完成的选型表

| 输入项 | 当前值 | 证据/责任人 |
|---|---|---|
| PCB/针排 FOV 宽×高 | 待实测 | 机械图 + 最大来料偏移 |
| 最小孔径/最大针径 | 待提供 | 产品图纸 |
| 针数量、针距、总跨度 | 待提供 | 产品图纸 |
| PCB 翘曲和针尖高度范围 | 待实测 | 工艺/量具 |
| 目标物方像素当量 | 初始 0.010～0.015 mm/px | 误差预算 |
| 允许曝光与节拍 | 待提供 | 节拍分解 |
| 背光可安装空间 | 待确认 | 机械布局 |
| 相机固定/眼在手上 | 待确认 | 设备运动方案 |
| 传感器分辨率/像元/尺寸 | 由上项计算 | 光学选型报告 |
| 镜头倍率/WD/远心度/畸变 | 由上项计算 | 实拍 DoE |
| 光源形式/尺寸/颜色/控制器 | 由真实样品实验 | 实拍 DoE |

这些数据补齐后，才能把“候选规格”收敛为具体厂商型号。
