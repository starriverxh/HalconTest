# 坐标系、标定与 XYT 原理

## 必须明确的坐标系

| 符号 | 坐标系 | 单位/方向 |
|---|---|---|
| `{Id}` | PCB 下视图像 | row 向下、column 向右，px |
| `{Iu}` | 针排上视图像 | row 向下、column 向右，px |
| `{Cd}` | PCB 相机 | 由相机模型定义 |
| `{Cu}` | 针排相机 | 由相机模型定义 |
| `{M}` | 机器基坐标 | X/Y mm，T 角方向按设备约定 |
| `{F}` | T 轴法兰/真实旋转中心 | 随 XYT 运动 |
| `{B}` | PCB CAD 基准 | 名义孔 P1...PN 所在坐标 |
| `{P}` | 针排工具基准 | 名义/实际针 P1...PN 所在坐标 |

记号 `^A T_B` 表示“把 B 坐标系中的点变换到 A 坐标系”。在代码和配方中不能只写 `point`，必须知道它是像素点、机器点还是产品点。

## row/column 为什么容易写反

HALCON 图像算子通常输出 `(Row, Column)`，而机械坐标通常写 `(X, Y)`。二维图像中常见对应是：

```text
Column ≈ 图像X方向
Row    ≈ 图像Y方向（向下）
```

但机器 Y 的正方向未必向下，镜头还可能旋转或镜像。因此不能直接写 `X=Column*scale, Y=Row*scale`；必须用已验证的变换。

## 相机内参与畸变标定

完整相机标定解决：焦距/放大率、主点、像素尺寸、镜头畸变和相机相对工作平面的姿态。HDevelop 常见算子链：

```text
create_calib_data
set_calib_data_cam_param
set_calib_data_calib_object
find_calib_object
calibrate_cameras
get_calib_data
image_points_to_world_plane
clear_calib_data
```

每台相机独立标定。输出至少绑定：相机序列号、镜头 ID、图像宽高、像素格式、工作距离、工作平面 Z、标定板 ID、HALCON 版本、温度和日期。

## 九点标定真正做什么

九点/多点平面映射用多组已知关系拟合：

```text
(imageColumn, imageRow) → (machineX, machineY)
```

简单仿射可用：

```text
vector_to_hom_mat2d
affine_trans_point_2d
```

它能表示平移、旋转、缩放和剪切，但不能完整表示普通镜头的径向畸变，也不能解决物体离开标定平面后的视差。若存在透视，可先去畸变后使用平面单应性；高精度项目优先使用完整相机模型和世界平面转换。

九点只是最低数量示例。实际应让点覆盖有效 FOV 的中心、四边和四角，并增加独立验证点。

### 拟合点和验证点必须分开

- 拟合点：用于求变换参数；
- 验证点：不参与求解，只用于检查模型在新位置的误差；
- 重复点：同一机械位置多次采集，用于测重复性。

只把自己拟合过的九个点再代回去，不能证明泛化误差。

建议初始门槛（需由误差预算确认）：拟合 RMSE `≤0.010 mm`、独立验证最大误差 `≤0.020 mm`、点位覆盖有效 FOV 至少 80%。

## PCB 位姿不是“孔中心平均值”

给定 PCB CAD 中有编号的名义孔 `b_i`，相机测得机器坐标 `m_i`，求刚体变换：

```text
^M T_B = argmin Σ wi · ||m_i - (R·b_i + t)||²
```

这会同时利用所有孔，输出旋转、平移和每个孔残差。应检查：

- ID 是否一一对应；
- 是否缺孔/多孔；
- 点是否近似共点或几何退化；
- 单孔残差、RMSE、最大残差；
- 异常点剔除后是否仍有足够几何约束。

## 针排也必须逐针测量

针排不能用配方中的固定姿态替代真实相机。上视相机每周期应输出：

```text
P1 → (X1,Y1)
P2 → (X2,Y2)
...
PN → (XN,YN)
```

同时检查缺针、弯针、针距、直线度、轮廓和分数。只有真实针点和真实孔点都存在，才能产生量产运动许可。

## N 点针孔刚体对齐

将同 ID 的针点 `p_i` 对齐到孔点 `h_i`：

```text
min Σ wi · ||h_i - (R(Δθ)·p_i + t)||²
```

二维闭式求解：

1. 分别计算针点质心 `p̄` 和孔点质心 `h̄`；
2. 对中心化点累加 dot 和 cross；
3. `Δθ = atan2(cross, dot)`；
4. `t = h̄ - R·p̄`；
5. 将每根针变换后计算 `e_i = ||h_i-(R·p_i+t)||`。

量产判定看 `max(e_i)`，不能只看两个中心或平均误差。

## 为什么不能直接做 `boardPose - pinPose`

二维刚体变换不是普通三维向量。平移与旋转的顺序会改变结果；机械 T 轴又通常围绕一个不在机器原点的点旋转。直接做 X/Y/角度相减忽略了这种耦合。

假设点列拟合得到：

```text
q = R·p + t
```

设备命令定义为“先绕机器点 `C_T` 旋转，再做 XY 平移”。绕点旋转本身已经产生：

```text
(I - R)·C_T
```

因此轴平移命令是：

```text
ΔXY_axis = t - (I - R)·C_T
```

V2 的 `RigidAlignmentSolver` 实现并测试了这一公式。若真实设备是先平移后旋转、T 轴位于局部法兰系或控制器使用不同角度符号，公式必须按设备运动学重新定义，不能只改正负号试出来。

## T 轴真实旋转中心标定

让固定在 T 轴上的视觉特征在多个角度拍照并转换到机器坐标；理想轨迹是圆：

1. 在至少 5～9 个角度采集，覆盖工作角度范围；
2. 每个角度重复多次；
3. 拟合圆心得到 `C_T`；
4. 分开 CW 和 CCW 数据，检查回差；
5. 检查圆拟合残差、不同半径/不同 Z 高度一致性；
6. 使用未参与拟合的角度验证。

只在 `T=0°` 做 XY 九点标定，不能得到 T 轴中心。

## 完整双相机关系

下视相机测得 PCB：

```text
^M T_B = FitRigid(PCB名义孔B → 下视测得孔M)
```

上视相机在拍照轴位 `q_up` 测得实际针排。若针排安装在法兰上：

```text
^F T_P = inverse(^M T_F(q_up)) · ^M T_P
```

目标法兰姿态：

```text
^M T_F_desired = ^M T_B · ^B T_P_desired · inverse(^F T_P)
```

再根据设备控制器的 XYT 定义分解成轴命令。曝光时必须同步保存轴反馈；只知道“Socket 已触发”不足以恢复这条关系。

## 标定失效条件

以下任一变化都应使相关标定变为 Invalid，必须重新验证或重标：

- 更换相机、镜头或相机采集卡；
- 改变分辨率、binning、采集 ROI 或像素格式；
- 改变焦距、对焦、光圈、工作距离、相机安装角；
- 移动光学支架、T 轴、治具或上视相机；
- 工作平面 Z 超出已验证范围；
- 标定过期、温度超范围或黄金验证点漂移超限；
- 文件哈希、硬件序列号或版本不匹配。

标定报告不仅保存一个 6 元素矩阵，还要保存原图、点表、残差、验证结果和硬件指纹，才能追溯。
